# Admin dashboard illustration

`growth-illustration.png` is the transparent 3D asset used by the previous neumorphic dashboard.
Both variants are retained as reference material; the current classic dashboard does not use them.
It was generated with the built-in imagegen tool, inspected, and copied into this repository.
The dashboard layout, chart, icons, gradients, and shadows are implemented as UI components/CSS.

Final generation prompt:

> Use case: stylized-concept. Asset type: transparent 3D illustration for the lower-right card of a neumorphic e-commerce admin dashboard. Create an isolated premium soft 3D render: a vivid royal-blue shopping bag with rounded handles resting on two stacked rounded white/periwinkle display plinths, a small rounded white analytics tile with three rising blue bars in front, and a small green leafy sprig behind on the right. Isometric front three-quarter view, soft clay-like smooth materials, subtle glossy blue highlights, gentle ambient occlusion, generous transparent padding. Match polished modern neumorphic SaaS dashboard illustration style. Blue #246bff, pale lavender-white, mint foliage. Composition square, fully visible objects centered. No text, no letters, no logos, no watermark. Genuine transparent alpha background. This is a small decorative UI asset, not an entire dashboard or screenshot.


`growth-illustration-dark.png` is the matching transparent dark-theme asset. Both files live in
`public/admin/` and are selected by the persisted admin theme. Created with the built-in imagegen
editing tool (not the fallback CLI), inspected, and copied into this repository.

Final dark-variant editing prompt:

> Use case: precise-object-edit. Edit target: the attached transparent shopping-bag dashboard illustration. Create its dark-theme counterpart, retaining the exact composition, framing, object sizes, isometric angle and transparent background. Change only the two stacked white/lavender display plinths at the bottom into deep charcoal/navy matte platforms (#1b2639) with subtle blue rim lighting. Keep the vivid royal-blue shopping bag, rounded handles, small white analytics tile with blue bars, and green leaves in exactly their existing positions. Use slightly richer electric-blue highlights and soft shadows suited to a dark neumorphic dashboard. Preserve clean transparent alpha edges. Do not add text, logos, objects, background, or watermark.
